# BT-083: Consider collectibles on long soft-ice courses

## Problem

During the BT-082 playtest the user suggested, after playing Spiral, that
collectibles could be considered. Optional pickups along a route could reward
taking the full path and add mastery goals without harder timing.

## Scope

Idea only. Collectibles would be a new puzzle system (data, simulation,
rendering, saves and records), which the project guidance excludes unless
explicitly approved. Requires a design decision before any implementation.

## Acceptance criteria
